04 · SET LOGGING OVERHAUL

Driven by real feedback from Leon — logging that respects your thumbs.

The core loop of the app is typing sets. So we rebuilt it Hevy-style: less typing, no ambiguity, and one nasty bug made structurally impossible.

Before · the bug

"Fill empties" model

Typing 24 left later sets stuck at 2 — the second keystroke never reached them. Fragile by design.

→
After · the fix

Store-what-you-type

Save only real keystrokes; compute ghosts for display. The multi-digit bug became impossible — backed by keystroke-simulating tests.

✓

+ Add set copies down

New set inherits weight + reps from the set above. No re-typing the same numbers.

✓

Remember where I was

Opening an exercise auto-selects the equipment tab you last logged; a lime dot badges every tab with history.

✓

Unambiguous PREVIOUS

Shows the unit — 20kg × 5 — so weight vs reps is never a guess.

✓

Aligned columns

SET / PREVIOUS / KG / REPS headers replace the cluttered inline row. (Per-set "done" checkbox dropped for now.)

★

Why it matters: this is where you spend every workout. Fewer taps, zero ambiguity, and a class of data-loss bug that can't come back.
