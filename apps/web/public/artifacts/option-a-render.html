4. Logs against exercise ID
What changes under the hood (Option A): the picker browses muscleGroups[] → exercises: Record<group, Exercise[]> (code-controlled, no user-custom). Selecting one writes its stable exercise_id into the session slot, and every logged set stores exercise_id — so history, gifs, muscle tags and steps all come from one source of truth. The Train card itself looks identical to today — just backed by a real exercise instead of a text name.
