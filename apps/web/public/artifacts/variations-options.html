Same-equipment variations — 4 options

The point you raised: "in dumbbells we can do different variations for the same muscle" — hammer curl, standing curl, incline curl, concentration curl all use dumbbells but hit biceps slightly differently. Right now the app supports one variation per equipment kind (bar / cable / machine / db / bw). Each option below shows how we could expose more.
Current data model (for context):
variations["Biceps curl"] = { bar: "Barbell Curl", db: "Dumbbell Curl", cable: "Cable Curl" }
One name per kind → one exercise_id per kind → one demo per kind. That's why swapping tabs currently only shows one option per equipment.
